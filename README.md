# E-Commerce Sales Data Analysis Using Python

## Project Overview
An end-to-end exploratory data analysis project using Python to analyze e-commerce transactions, understand sales performance, evaluate profitability and identify actionable business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Overview
- 4,200 cleaned transaction records
- 21 original data columns
- Customer, product, sales, profit, discount and shipping information
- Date range: January 2020 – December 2024

## Project Workflow
1. Data loading and inspection
2. Missing-value analysis and treatment
3. Duplicate detection and removal
4. Data type conversion and validation
5. Data-quality checks and anomaly flagging
6. Exploratory data analysis
7. Sales and profitability analysis
8. Customer satisfaction and returns analysis
9. Data visualization
10. Business insights and recommendations

## Key Findings
- Total recorded sales: 264.27 million monetary units
- Total recorded profit: 49.52 million monetary units
- Total orders: 4,200
- Return rate: 14.57%
- Average customer satisfaction: 3.02/5
- Electronics was the highest-sales product category.
- South was the highest-sales region.
- 2023 recorded the highest annual sales.

## Business Recommendations
- Investigate product return patterns.
- Improve customer satisfaction.
- Review discount strategies to protect profitability.
- Investigate unusually high-value transactions.
- Focus on high-performing products and regions.

## Limitations
Some missing and invalid numerical values were imputed or corrected. Extreme sales and profit values were flagged for investigation rather than automatically removed. The original monetary unit and sales calculation formula were not independently verified.
